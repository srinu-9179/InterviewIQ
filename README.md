# 🚀 InterviewIQ (LevelUp)

**InterviewIQ** (also known as LevelUp) is a data-driven, 2-minute assessment platform designed to objectively measure interview readiness. It evaluates candidates across technical skills, resume strength, communication clarity, and portfolio impact—perfect for students and new grads preparing for their first recruiter calls.

## ✨ Features

- **⏱️ 120s Assessment**: A quick, comprehensive evaluation taking only 2 minutes on average.
- **📊 4 Core Pillars Evaluated**:
  - **Technical**: DSA, system design, and project depth.
  - **Resume**: Quantified impact and ATS readiness.
  - **Communication**: STAR stories and elevator pitches.
  - **Portfolio**: Case studies and verifiable work.
- **🎨 Modern Animated UI**: A vibrant, dark-themed interface featuring floating orbs, glassmorphism cards, shimmer effects, and smooth, engaging animations.
- **🔒 Privacy First**: Zero logins, no cookies, and no tracking. Completely frictionless experience.

## 🛠️ Tech Stack

- **Frontend Framework**: [React](https://react.dev/) powered by [Vite](https://vitejs.dev/)
- **Routing**: [TanStack Router](https://tanstack.com/router/latest) for type-safe routing
- **Styling**: Tailwind CSS enhanced with custom vibrant gradients, glassmorphism, and keyframe animations
- **State Management**: React state hooks & [TanStack Query](https://tanstack.com/query/latest)

## 🚀 Getting Started

To get the project up and running locally, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/23kb1a3080-cloud/InterviewIQ.git
cd InterviewIQ
```

### 2. Install dependencies
Make sure you have Node.js and npm installed.
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:8080` (or `http://localhost:8081` if the default port is in use).
